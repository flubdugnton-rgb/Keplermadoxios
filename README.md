# Kepleræ iOS 1.1

Versão 1.1 do Kepleræ para iOS 27 em SwiftUI.

## Novidades 1.1

- catálogo real da versão Android com 1.022 conteúdos e organização por pastas;
- Pomodoro com ciclos, histórico e personalização;
- Questões com criação de matérias, registro de acertos/erros e histórico;
- Notas com blocos, busca, edição, exclusão e cores;
- perfil/configurações acessível pelo avatar na barra inferior;
- tema Sistema/Claro/Escuro, intensidade do Liquid Glass e backup JSON no perfil;
- ícone oficial do Kepleræ no iOS;
- versão 1.1 / build 2.

O login OAuth nativo do Google no iOS ainda requer um Client ID OAuth específico para iOS. O catálogo e os links do Google Drive já funcionam com os dados importados do Android.

# Kepleræ iOS 1.5.2

Hotfix visual e de usabilidade da versão 1.5.1.

## Ajustes 1.5.2

- fundo do app agora se estende pela área da barra de status, sem faixa branca no topo;
- navigation bar configurada como transparente para acompanhar o tema da tela;
- player de vídeo reduzido para proporção próxima de 16:9;
- botões Favoritar e Concluir permanecem acima da barra inferior e a tela pode rolar com folga;
- PDFs mantêm leitura grande e botão de tela cheia;
- fallback de vídeo/áudio inicia mais cedo quando o streaming autenticado do Drive não fica pronto;
- barra inferior Liquid Glass e navegação por gesto mantidas;
- catálogo continua com 1.022 materiais.
